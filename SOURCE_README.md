# Source notes — 22.9.2 skill-first rebuild

22.9.2 preserves the clean single-router/single-render architecture introduced in 22.9.0. It does not reintroduce the legacy stacked render layers.

Primary changes: compact sticky current-skill objective bar; top and bottom Previous/Next navigation; expandable skill explanations; multi-select 12-month trend identification; a separate visual difference-over-time exercise before formal statistical difference testing; and a fully manual, mistake-friendly Documentation checkerboard with compact cells and pinch-zoom support.
