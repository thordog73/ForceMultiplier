# Force Multiplier 22.13.1 — Source Notes

This release adds the MAJCOM-aware learner reference library to the 22.13.0 task map. The reference list is in `dist/references-data.js`, the UI and native download/share behavior are in `dist/references.js`, and styles are in `dist/references.css`.

All online references are HTTPS links to the official e-Publishing domain. Each direct PDF is only a discovered, published example until currency and local applicability are checked on the official source-of-record site. The application does not have an e-Publishing change feed and never certifies that a saved PDF is the controlling document.

Existing training activities remain fictional educational exercises. Passing a simulation does not grant official MXMGR qualification.
