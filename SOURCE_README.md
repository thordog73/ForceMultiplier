# Force Multiplier 22.15.0 — Source Notes

The learner-facing References tab, PDF downloads, and MAJCOM reference browser have been removed, as requested. The simulator continues to teach how to establish controlling facts and authorized evidence, but does not attempt live publication lookup.

All 35 fundamentals and 72 task entries use explicit semantic diagram assignments defined in `dist/visuals.js`. Three Wrong / Right / Constraint variants illustrate each task. `dist/teaching.js` creates the gallery; `dist/task-map.js` applies the actual source task and its evidence criteria instead of the nearest lesson’s generic content.

The fixed dialog-scroll behavior is in `dist/fm2290.js` and has been tested on a mobile-sized Chromium browser. Current user progress and training evidence persist; only answers to the rewritten task-specific quizzes are cleared at first launch of this version.

All examples are fictional educational cases. Actual technical-school SME validation and device-level QA remain required. A simulation does not establish Air Force qualification.
