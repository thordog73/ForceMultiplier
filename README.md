# Force Multiplier 22.9.2

Offline maintenance-management training simulator.

22.9.2 makes the learner's current skill—not the broad module—the persistent on-screen anchor. Every exercise has a compact sticky skill/objective bar with expandable explanation and Previous/Next navigation at the top, while the full controls remain at the bottom.

Analysis now asks learners to select every chart showing a sustained trend, separately recognize step-changes/differences across 12 months, then proceed into formal difference testing, Fishbone, correlation, countermeasure, and verification.

Documentation now uses a smaller manual 24-aircraft checkerboard. Learners may place R1, R2, G1, G2, Cure, or erase in any cell—including wrong placements—then use Check Fleet Plan for feedback. The board explicitly supports pinch-to-zoom and horizontal/vertical scrolling.
