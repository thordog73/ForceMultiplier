# Force Multiplier 22.9.1

Clean learner-facing rebuild of the offline maintenance-management simulator.

22.9.1 adds real Difference/Correlation calculations in the clean Analysis path, six possible Big Boss outcome patterns, interactive Documentation Inspection/Phase Flow, and answer-length bias checks.

## Five functions
- Scheduling: seven isolated core skills plus vocabulary.
- Analysis: 20 metrics, acquisition comparison, and one continuous Improvement/Analysis Simulator.
- Documentation: direct 24-aircraft modification planner, control terms, inspection flow, and Phase Flow.
- Data Integrity: maintenance record fields and ten reconciliation/correction skills.
- Database & Systems: seven visual access/troubleshooting/change/recovery skills.

The released `dist/index.html` loads only `fm2290-model.js`, `fm2290.js`, `fm2290.css`, and the native bridge. Legacy training assets remain in the source package for reference/model regression tests but are not loaded into the released learner UI.
