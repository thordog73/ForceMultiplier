# Force Multiplier 22.6.4 — Commander Questions + Actual Data Fishbone

## Metric interrogation
Each of the 20 acquisition metrics now provides three learner/commander views: what the metric means, what a high/low value can suggest, and organic follow-up questions/related metrics. These prompts are phrased as operational questions rather than handbook citations.

## Actual Data mode
The Gold Rat Fishbone Test Builder retains all 13 tests and adds optional local-session CSV/paste analysis. The learner still constructs question family, data structure, H0, H1, alpha, and test before mapping columns. Raw imported rows are held in memory only and are not written to saved progress.

The local calculator supports Kendall/Mann-Kendall, F variance, two-sample Welch t, Z mean, Z proportions, ANOVA, Mann-Whitney, Kruskal-Wallis, chi-square goodness-of-fit, chi-square independence/homogeneity, Pearson, and Spearman. Cochran's C reports the C statistic but intentionally does not claim an exact p-value for arbitrary samples; consequential significance decisions should be verified in approved statistical software.

Do not load classified, CUI, PII, medical, export-controlled, or other sensitive operational data.
