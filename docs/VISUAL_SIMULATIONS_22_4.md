# Force Multiplier 22.4.0 — Visual Simulations

The learner does major work products rather than completing 100 separate lessons. The canonical 100-skill map is retained as a hidden coverage/scoring framework.

## Scheduling progression
1. 6-turn-4
2. 12-turn-10
3. 12-turn-10 with availability, priority, configuration and turnaround constraints
4. Weekly checkerboard
5. Modification week: parts, cure, capacity and operating requirement
6. Inspection and flow balancing
7. Parts delay / recovery planning
8. Disruption drill
9. Scheduling decision meeting
10. Execution review

Each reset changes the conditions. The intent is repeated performance on the same visual work product until the patterns become familiar. One simulation can cover several underlying skills at the same time.

## Other functions
- Analysis: charts, rates, trends, drivers, comparisons, options and recommendations.
- Documentation: requirements, due points, attachments, signatures, workflow states and handover.
- Data Integrity: identity matching, side-by-side extracts, discrepancies, corrections and downstream verification.
- Database & Systems: workflows, access, logs, imports, outages, recovery and closure.

## Visual design
Generic visual language only. No military insignia, fighter-aircraft imagery, rank, official branding, or official qualification claims. Generic resource identifiers and fictional records are used.
