# Force Multiplier 22.8.4 — 24-Aircraft Early Scheduling Pool

## Kept intact
- Existing aircraft-card visual design with large READY / LIMITED / PRIORITY / UNDERUSED / UNAVAILABLE cues.
- Scheduling 100-repetition battle rhythm and progressive Phase Flow.
- Analysis 100-repetition month-to-month battle rhythm.
- Documentation 24-aircraft monthly modification rollout.
- Universal Show Me / re-simulation and open skill navigation.

## Changed
- Early Scheduling now uses a 24-aircraft AMU so the learner has genuine selection choices instead of being forced to use every available aircraft.
- Real unavailability labels are visible immediately: NMC, CANN, PHASE, DEPOT and MOD. Early in training, they all have the same immediate rule: the aircraft is unavailable and stays off the flyer.
- The meanings of those labels are progressively explained later without changing the familiar card layout.
- The opening block starts with 6-turn-4 for the first few repetitions, then moves into 12-turn-10 while staying in the same 24-aircraft fleet.
- FHP execution and limitation blocks use 24 aircraft throughout.
- Phase-hours information remains progressively revealed on the same aircraft cards so the learner first asks “Can I fly it?” and later “Should I fly it, given the future Phase Flow?”

## Training intent
The learner grows into the same fleet screen: first recognize availability, then understand why aircraft are unavailable, then use spare capacity and aircraft choice to protect future Phase flow while still executing the FHP.
