# Release Notes — Force Multiplier 22.10.0

## Block Academy campaign

Seven themed missions with 90 deterministic, progressively more constrained practice cases apiece. Aircraft block scheduling in Missions 1–3, sequenced maintenance documentation in 4, rate inputs in 5, evidence-based record reconciliation in 6, and DBM permissions and verification in 7. A saved-progress gate counts only independent correct exercises; showing a model does not grant credit.

## Interface

Bright colored blocks with larger labels, pointer-based drag-and-drop including touchscreen, tap-to-place fallback, quick-access mobile drag rack, flight-line doorway launch animation, Home button on every game screen, and Flashcards directly available from the menu and header.

## Preserved

Original advanced trainers, Scheduling 90-day Capstone, single router, offline operation, privacy manifest, bundle identifier, signing integration, and TestFlight workflow.

## QA

630 generated case models plus route/interaction regression; existing model, scoring, 20-user navigation, documentation, analysis, database, uploader, and 90-day capstone tests. This is automated/browser-level validation, not a signed iPhone build or Apple approval.
