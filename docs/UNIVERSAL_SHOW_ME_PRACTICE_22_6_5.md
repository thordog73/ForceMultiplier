# Force Multiplier 22.6.5 — Show Me + Unlimited Practice

## Intent
Every exercise can be used as instruction or independent practice. Learners can reveal the correct current-case answer without being blocked, then generate another version of the same skill and repeat indefinitely.

## Global controls
- **Show Me the Right Answer** fills or selects the model answer for the current generated case and provides a short explanation.
- **Re-simulate Question** keeps the learner on the same skill while regenerating the scenario conditions.
- Assisted answers unlock navigation but do **not** add independent skill-coverage credit.

## Coverage
The controls apply to Scheduling, Analysis (including acquisition, Improvement Laboratory and Fishbone), Documentation, Data Integrity, Database & Systems, and the optional Worlds practice surface.

## Stress checks
- Full regression suite passes.
- Model answers for all advanced Scheduling checkerboard levels were validated across 60 seeds.
- A browser interaction harness performed 1,000 rapid Show Me / Re-simulate actions with no JavaScript errors.
- Improvement Laboratory and Fishbone assisted answers preserve the currently generated case and test selection.

## Training boundary
Show Me is a teaching aid, not evidence of independent proficiency. A learner can study the worked answer and continue, then use Re-simulate Question for a fresh independent attempt.
