# Force Multiplier 22.4.1 — Focused Scenario Mode

When a learner enters a simulation, the simulation becomes the entire training surface.

- Global function tabs are hidden.
- Scenario navigation is hidden.
- Skill coverage/progression UI is hidden.
- Global footer and other-world links are hidden.
- A small **Exit Scenario** control remains available.
- The learner sees only the active work product, its task controls, feedback, and any scenario-specific coach/evidence panels.

The first Scheduling simulation is the basic 6-turn-4. More complex scenarios preserve the same focus behavior.
