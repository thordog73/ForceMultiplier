# Force Multiplier 22.7.1 — Monthly modification to daily scheduling flow

## Scheduling flow correction

- Removed the live “Balance future workload” detour from the 20-level Scheduling progression.
- After RED/GREEN modification timing and compatible-work practice, learners now build a four-week modification schedule using the actual RED and GREEN labels rather than generic Work boxes.
- The monthly modification exercise accepts any arrangement that keeps all packages inside their permitted week windows and respects the two-package-per-week training capacity.
- The next level zooms directly into Week 2 and converts those monthly commitments into a daily schedule.
- The daily schedule inherits RED work, GREEN work, and 24-hour cure blocks. Those maintenance commitments cannot be erased to make the flying plan easier.
- Open daily cells cycle Idle → Fly → Spare → Idle. The rule-based grader accepts any lineup that produces exactly five flyers and one protected spare per day while preserving the modification downtime.
- Wrong placements and wrong daily choices remain editable after checking; no reset is required to correct an answer.
